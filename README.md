# 页间 / Between Pages

项目交付与维护见 [交付文档](docs/HANDOFF.md)；开发电影、艺术品等衍生项目见 [盲盒模板扩展指南](docs/VARIANTS.md)。

中文阅读盲盒。React 19、TypeScript、Vite、Motion，配套本地 Node API。提供“推敲选书”和“随手抽书”：每八小时五次推敲机会，随手抽书不限次数且不调用生成服务。随手抽到后可主动使用机会补介绍。另有口令保护的私用无限测试版。运行与配置见 [SERVER.md](SERVER.md)。

## 本地运行

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5173/ 。构建：`npm run build`，输出 `dist/`。

## 三幕交互

- 纸签：按心情、想得到什么、MBTI、氛围、类型、怎么读分组，每手最多六张扇形牌。点击或向下拖动留下，左右推牌或按钮换一手，切换主题保留选择。其他纸签包含完整分类与自定义线索。
- 包裹：进入后自动找书，找到前封带锁定；提示“书已备好”后，右拉纸带或点击「拆开」。取消拖动会回弹，拆封期间锁定重复操作。
- 书：左划或点击翻开，右划换一本。详情、阅读平台、来源放在书内，收藏与历史收在角落。

酒红桌面、石灰白纸牌、短文案、全屏舞台和纸张动画。支持 reduced motion；小屏书内详情独立滚动。

## 自动外部书库

进入拆书页后由服务器获取 Open Library 随机候选并计数。纸签对应主题查询，限制有中文版本的作品，优先采用中文版本书名，并排除仅有拼音/外文标题的记录。Open Library 不可用时尝试 Google Books 的中文书目。抽取在本轮外部候选中完成，保留随机探索与最近八本避重；并非对全球书目严格等概率抽样。

浏览器保存最多 500 条外部记录、20 条抽取历史及收藏 ID。断网只使用之前缓存的中文外部书目，首次离线会提示重试。旧版 36 本书仅用于恢复已有收藏/历史，不进入新抽取池。外部服务响应、中文元数据与简介覆盖率会影响可用结果；不生成不存在的简介或阅读权限。

封面是页间排印设计，并非出版商封面。平台搜索链接不代表免费可读，阅读权限以具体平台和版本为准。

## 验证

```sh
npm run build
npm test
npm run lint
npm run build
node tests/immersive.mjs
node tests/immersive-touch.mjs
```

浏览器脚本使用本机 Edge。`immersive.mjs` 测试三种屏幕尺寸、自动抽取、取消、自定义线索、收藏、避重、缓存、无缓存断网、axe 和真实书库请求；真实网络部分单独输出结果。旧版 browser/catalog/edge-cases/accessibility 脚本保留作历史参考，不适用于新界面。

新版扇形牌组与左右滑动验证：`node tests/fan.mjs`。服务端限额与模型接口已实现；本地使用需要自己配置 `.env.local`。当前自动测试包括 Worker/D1 集成测试，因此首次运行 `npm test` 前需先构建。浏览器动作回归见 `tests/motion-flow.mjs` 和 `tests/upgrade-flow.mjs`；部分历史脚本仍使用旧版限额或界面，仅作参考。
